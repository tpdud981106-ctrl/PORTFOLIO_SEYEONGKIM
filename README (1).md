## 1️⃣ 한국해외인프라도시개발지원공사(KIND) 인턴
**2026.05 – 현재**

- 해외 인프라·도시개발 사업 마스터파일(기초자료) 작성 — 문서함 자료를 취합·검토해 위원회·보고 자료의 기초 구축
- 컨소시엄 구성, 참여사 간 지분·역할 관계 정리 및 사업 분담비율 검토
- 투자금 규모, 재무구조, IRR 등 핵심 재무지표 정리 — 사업 타당성과 연결해 해석
- 정량평가 항목별 산출근거 확인 — 평가결과와 제출자료 간 정합성 크로스체크, 오류·누락 발견 시 공유·수정 지원
- 위원회 준비, 외부위원 섭외 등 팀 서무 및 행정지원, 회의록 작성

`재무지표 이해` `문서화 역량` `꼼꼼함/검증력` `행정지원`

## 2️⃣ 도시경관 연경 근무
**2026.01 – 2026.04**

- 강화군·화성시 경관계획 보고서/제안서 작성 보조, 경관계획 내 삽도 제작 (일러스트레이터, 한글, 엑셀)
- 경관자원 데이터 지오코딩 작업 수행

**💡 프로세스 개선 사례**

| 단계 | 내용 |
|---|---|
| 1. 문제 인식 | 구글 스프레드시트 기반 지오코딩 → 국내 장소 정보 부족으로 좌표 오류 빈발 |
| 2. 대안 전환 | 국내 데이터베이스가 더 정확한 카카오맵 API로 전환하여 재수행 |
| 3. 결과 | 좌표 오류를 크게 개선하고 경관자원 데이터 신뢰도를 높임 |

`문제해결력` `데이터 가공` `보고서 작성`

## 4️⃣ 노량진 청년창업센터 졸업설계 프로젝트
**2025-1학기 팀프로젝트**

- 노량진 청년창업센터 구상 — 주제·대상지 선정 및 타당성 조사 후 사업구조 기획
- 공공데이터포털 데이터를 활용한 다양한 GIS 분석 수행
- 주소가 없는 데이터는 직접 수집·지오코딩하여 분석에 활용 — 데이터 가공 능력

`GIS 분석` `데이터 가공` `다중툴 활용력`
